# TOOLS.md – Loop Persona Tools

## Codebase Reading

- **Read** – Understand issue context and prior iterations
- **Grep** – Find related issues or prior attempts

## Adapter Operations

- **get_issue** – Read full issue including iteration history
- **list_comments** – Check feedback from prior cycles
- **save_comment** – Post iteration notes and retry status
- **set_state_label** – Mark issues as ready for next iteration
- **update_state** – Move issues between iteration states

## NOT Available

- **Write/Edit** – Do not modify source code
- **Bash** – Do not run tests or scripts
