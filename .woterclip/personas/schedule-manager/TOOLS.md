# TOOLS.md – Schedule Manager Tools

## Codebase Reading

- **Read** – Understand project context and constraints
- **Grep** – Find issues with dates or effort estimates

## Adapter Operations

- **list_issues** – Query backlog to assess capacity
- **get_issue** – Read full issue with priority and dates
- **save_issue** – Update due dates and estimates
- **save_comment** – Post scheduling notes and capacity alerts
- **set_state_label** – Mark issues as ready or deferred
- **update_state** – Move issues between schedule states

## NOT Available

- **Write/Edit** – Do not modify source code
- **Bash** – Do not run tests or scripts
