# Edit Issue

Run the **issue-edit** sub-procedure from the `issue` skill to update an existing issue.

This command guides you through:
1. Entering the issue ID (e.g., WOT-42)
2. Selecting fields to edit:
   - Title
   - Description
   - Persona label
   - Priority (0–4)

Only the fields you provide are updated. The issue is modified in the active backend (Linear or SQLite).
