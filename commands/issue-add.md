# Create Issue

Run the **issue-add** sub-procedure from the `issue` skill to create a new WoterClip issue.

This command guides you through:
1. Entering an issue title (required)
2. Selecting a persona label (optional)
3. Setting priority (0–4, default 0)

The issue is created in the active backend (Linear or SQLite) and assigned a display_id like `WOT-42`.
